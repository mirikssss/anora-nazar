# backend

Сервисы на Python. Один проект и один образ; сервис выбирается командой запуска. Фоновые задачи работают внутри процесса сервиса. У каждого сервиса своя база в общем экземпляре PostgreSQL и свои миграции.

| Пакет | Сервис | База |
| --- | --- | --- |
| `src/node` | узел Anora Nazar | `node` |
| `src/bank_sim` | имитатор банка | `bank_sim` |
| `src/network_operator` | оператор сети кредиторов | `network_operator` |
| `src/anchor` | якорь журнала | `anchor` |
| `src/world` | генератор синтетики (команда) | пишет в `bank_sim` и `network_operator` |
| `src/shared` | общий код без доменной логики | — |

## Модуль

Каждый модуль — папка в `modules/` сервиса:

| Файл | Что внутри |
| --- | --- |
| `api.py` | роутер: валидация, права, вызов сервиса |
| `schemas.py` | схемы входа и выхода API |
| `service.py` | сценарии использования, границы транзакций |
| `domain.py` | чистая логика без ввода-вывода |
| `repository.py` | доступ к БД |
| `models.py` | таблицы |

Зависимости: `api → service → domain / repository → models`. Чужие репозитории и таблицы не используются — только сервисы других модулей или события.
