# params

Файлы параметров генератора. Каждое значение согласуется с владельцем и опирается на публичные агрегаты.

- `world-v1.yaml` — мир проверок моделей И2–И3 («Проверка моделей на синтетике»); остаётся для воспроизводимости.
- `world-v2.yaml` — world-v1 и межбанковые схемы с ловушками сети кредиторов (И4): разделы `other_lenders`,
  `honest.cross_lender`, `fraud.cross_lender`. Без этих разделов генератор даёт прежний мир world-v1.
