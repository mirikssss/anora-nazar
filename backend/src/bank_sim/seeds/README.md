# seeds

Сиды имитатора банка, загружаются командой `python -m bank_sim seed`:

- `roles.yaml` — роли имитатора;
- `branches.yaml` — филиалы и сотрудники для И1 и онлайн-канал;
- `borrower_personas.yaml` — персоны заёмщиков для приложения банка.

`scenarios.yaml` — готовые сценарии трёх зон; читается имитатором при запуске сценария.
