# frontend

Интерфейс всех ролей: React, TypeScript strict, Vite. Правила вида и страницы — в `CLAUDE.md`.

## Слои

| Папка | Что внутри |
| --- | --- |
| `src/app` | корень, роутер, провайдеры |
| `src/pages` | страницы, по папке на роль |
| `src/widgets` | составные блоки страниц |
| `src/features` | действия пользователя |
| `src/entities` | сущности: типы, запросы, мелкие компоненты |
| `src/shared` | API-клиент, UI-примитивы, токены, иконки, словарь, утилиты |

Импорт только вниз: `app → pages → widgets → features → entities → shared`. Фронт ничего не считает и не зашивает — данные только с бэка; строки — только из `shared/i18n/ru.ts`; иконки — только через `shared/icons`.
