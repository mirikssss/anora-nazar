# frontend

Интерфейс всех ролей: React, TypeScript strict, Vite. Правила вида и страницы — в `CLAUDE.md`.

## Слои

| Папка | Что внутри |
| --- | --- |
| `src/app` | корень, роутер, провайдеры |
| `src/pages` | страницы, по папке на роль |
| `src/widgets` | составные блоки страниц |
| `src/features` | действия пользователя |
| `src/entities` | сущности: типы, запросы, мелкие компоненты |
| `src/shared` | API-клиент, UI-примитивы, токены, иконки, словарь, утилиты |

Импорт только вниз: `app → pages → widgets → features → entities → shared`. Фронт ничего не считает и не зашивает — данные только с бэка; строки — только из `shared/i18n/ru.ts`; иконки — только через `shared/icons`.

## Формы

У каждого поля свободного ввода — пример значения (`suggestion` у `TextField`): виден вместо плейсхолдера, Tab или нажатие на метку «Tab» подставляет его. У формы — «Заполнить примером». Генератор — `src/shared/demo`: форматы как в `backend/src/world`, значения каждый раз новые. Это исключение из правила «демо-данные только с бэка» по указанию владельца; новые формы делаются так же.

## Команды

Всё через Docker из корня репозитория (CLAUDE.md, правило 7):

| Что | Команда |
| --- | --- |
| стенд с интерфейсом | `docker compose up --build -d`, интерфейс — http://localhost:5180 |
| проверки: eslint, prettier, tsc, сборка | `docker compose --profile test run --rm web-check` |
| обновить OpenAPI и типы после смены API бэка | `docker compose exec web npm run api:pull` и `docker compose exec web npm run gen:api` |

Адреса сервисов и часовой пояс задаёт compose (`VITE_*`, `WEB_*`). Интерфейс ходит в узел и имитатор банка через один адрес: `/api/node`, `/api/bank`. Порт 5180 на хосте выбран потому, что 5173 занят другим проектом.

План и статус — `ITERATIONS.md`.
