# Anora Nazar

Шлюз проверки заявки на кредит. Перед любой выдачей узел даёт зелёный, жёлтый или красный уровень с причинами и выдаёт разрешение, по которому банк двигает деньги. Закрывает три слепые зоны обязательных проверок № 3759: воля заёмщика, связи между заявками, суть проекта. Проект финала WIUT 2026.

Данные на стенде синтетические: их создаёт генератор проекта, распределения условные, реальных персональных данных нет.

## Структура

| Папка | Что внутри |
| --- | --- |
| `backend/` | сервисы на Python: узел `node`, имитатор банка `bank_sim`, оператор сети `network_operator`, якорь журнала `anchor`, генератор синтетики `world` |
| `frontend/` | интерфейс всех ролей на React |
| `deploy/` | выкладка на сервер |
| `docs/` | продукт: проблемы, архитектура, потоки, признаки, политика |

Правила разработки — `CLAUDE.md`.
