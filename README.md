# Anora Nazar

Шлюз проверки заявки на кредит. Перед любой выдачей узел даёт зелёный, жёлтый или красный уровень с причинами и выдаёт разрешение, по которому банк двигает деньги. Закрывает три слепые зоны обязательных проверок № 3759: воля заёмщика, связи между заявками, суть проекта. Проект финала WIUT 2026.

Данные на стенде синтетические: их создаёт генератор проекта, распределения условные, реальных персональных данных нет.

## Структура

| Папка | Что внутри |
| --- | --- |
| `backend/` | сервисы на Python: узел `node`, имитатор банка `bank_sim`, оператор сети `network_operator`, якорь журнала `anchor`, генератор синтетики `world` |
| `frontend/` | интерфейс всех ролей на React |
| `deploy/` | выкладка на сервер |
| `docs/` | продукт: проблемы, архитектура, потоки, признаки, политика |

Правила разработки — `CLAUDE.md`.

## Запуск

Нужен Docker. Секреты для разработки создаёт скрипт, потом стенд поднимается одной командой:

```bash
./deploy/dev-env.sh
```

```bash
docker compose up --build -d
```

| Сервис | Адрес | Документация API |
| --- | --- | --- |
| узел | http://localhost:8000 | http://localhost:8000/docs |
| имитатор банка | http://localhost:8001 | http://localhost:8001/docs |
| якорь журнала | http://localhost:8002 | http://localhost:8002/docs |

Общий синтетический мир строится один раз на чистом стенде. Генератор создаёт 11 месяцев истории банка, она прогоняется через узел — около 15–20 минут. Затем обучаются модели, и два риск-менеджера выпускают их в общий мир:

```bash
docker compose --profile setup run --build --rm world
```

```bash
docker compose --profile setup run --rm train
```

Все тесты — юнит, интеграционные на PostgreSQL и сквозные против поднятого стенда. Код монтируется томом, пересборка нужна только после смены зависимостей:

```bash
docker compose --profile test run --rm tests
```
